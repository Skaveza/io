## Projects

### Radahworks
An AI-powered three-sided marketplace connecting founders, professionals, and admins. I work on both backend and ML systems — built out the test suite, set up CI/CD, and helped build the platform's core dashboards.
**Stack:** PHP, Firebase, Stripe, React, TypeScript, Vite

### UwezoKYC
My capstone project — a receipt-based KYC scoring system that gives investment platforms an alternative way to verify users, built around a model that reads and understands document layouts (macro-average F1 of 0.95).
**Stack:** LayoutLMv3, Python

### WaterPath Kenya
A water resource management platform serving over 60,000 residents in Turkana County. It predicts water quality, maps boreholes, and gives NGOs and government bodies a dashboard to track accountability — built with multilingual access in mind.

| Layer | Technology |
|---|---|
| Frontend | React + Tailwind + Leaflet.js |
| Backend | Python + Flask |
| Database | Firebase Firestore (real-time) |
| Auth | Firebase Authentication |
| SMS / USSD | Africa's Talking API |
| ML | scikit-learn + pandas |
| Hosting | Vercel (frontend) + Railway (backend) |

### HealthBridge
A concept for improving healthcare access for refugees and people in conflict-affected areas — exploring how providers can reach people in high-conflict zones without the system being misused.
**Status:** Concept / early-stage
